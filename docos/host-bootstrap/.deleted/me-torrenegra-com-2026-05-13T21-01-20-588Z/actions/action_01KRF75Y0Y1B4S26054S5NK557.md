# Step 3 — Read the thought

Code: `post.html` + `post.js` + `blocks.js`.

The detail page is intentionally minimal:

- Single H1 (linked back to `/`) instead of the full hero, so the page is body-first.
- The `<article id="post">` block is filled by `post.js` reading `?id=` from the URL, fetching the same `posts.json` the feed uses, and rendering the matching post via `PostBlocks.renderBlocks`.
- The same language-fallback note logic applies — a thought published only in Spanish still renders for an English-default reader with an italic note.
- The newsletter CTA repeats at the bottom; the most engaged readers (people who finished a thought) get one more nudge.

The admin toolbar and editor live in the same HTML but start with the `hidden` attribute set. `post.js` flips them on only after an admin auth check; for an anonymous reader they never appear. That's why the admin flow lives in its own user-flow even though it shares a page.
